# 文明火种

一个无需安装、电脑横向与手机竖向自适应的蛮荒生存肉鸽原型。直接用浏览器打开 `index.html`，选择难度即可试玩。

- 资源：页面打开只预载主角、首个敌人和基础地形，其他贴图按实际出现懒加载，避免手机启动时并发请求和解码内存峰值；WebP 加载失败会自动切换到同名 PNG，最终失败仍保留简易图形兜底并在控制台标明素材路径。
- 手机：保持竖屏运行，不请求横屏锁定；左下方向圆盘移动，右下四键为脉冲、疾驰、飓风和护壁；摇杆与技能键使用独立触点，可双指同时移动与释放技能。
- 电脑：使用横向 16:9 游戏区；WASD 或方向键移动；空格释放「演化脉冲」，Q「疾驰」穿过险境，E 投出「飓风」，R 开启「祖灵护壁」。
- 难度：游猎、迁徙、试炼三档分别影响敌人生命、伤害、速度、刷新频率、受击间隔与补给频率；同一种怪物的基础移速倍率依次为 0.90 / 1.00 / 1.13。
- 关卡：潮痕海岸 → 苔木密林 → 火山荒原；每阶段战斗 40 秒后出现本阶段 Boss：潮涌巨蟹、古木守卫、赤焰巨猿。每击败一个 Boss，主动技能上限 +2、符文上限 +1，并提高弹幕、环绕扇、石矛上限，同时增加生命上限与伤害、获得回血和主动技能冷却重置；击败第三阶段 Boss 后进入无尽轮回，火山阶段和敌人会持续增强。无尽轮回的 Boss 只从六种火山 Boss 中轮换；潮涌巨蟹和古木守卫从第 1 轮起作为真正的精英怪持续刷新，不占用小怪或 Boss 名额，保留潮环、叶扇、根阵等独有技能，并随轮次提高生命、移速、攻击频率、弹幕数量、伤害和 Debuff 强度。精英不按每轮固定数量结算，场上持续刷新且刷新间隔会随轮次缩短；为保证手机端性能，同时最多保留 8 只精英。Boss 数量按每两轮增加 1 只，最多 4 只，普通敌人刷新量也会随轮次增加。
- 战斗：自动攻击会经历萌芽 → 猎手 → 火种三段成长；每次升级都会提高最大生命、伤害和移速，并回复当前最大生命值 50%；升级所需经验曲线已下调，升级节奏更紧凑；升级时还可学习连锁电弧与旋骨飞轮。环绕攻击使用羽扇贴图；三项主动技能分别提供闪避、飓风穿透与减伤解弹。开放地图会持续出现远离当前视野的遗迹，击破后可将 Q/E/R 分别升至 15 级并随 Boss 击败继续解锁上限，后段数值会渐进膨胀。
- 敌技：双发酸液、蓄力冲刺、震击、护壳、孢子扇射、投矛、毒液禁锢区、贴图火焰与 Boss 二阶段火扇等技能会因生物而异；无尽小怪会逐轮获得更快、更密集的低阶技能；潮涌/古木精英会用潮蚀、缚根附加迟滞、禁锢和受伤增幅，火焰 Boss 的火球、火雨和熔岩践踏会附加灼烧，持续掉血，二阶段效果更强；砂砾虫与野人低血量时会狂暴并提前冲刺，步兵投矛后短暂举盾。
- 拾取：野果（回复）、火种（重置脉冲）、兽骨（穿透）、引力晶核（吸收全图样本）、疾风孢子（加速）、祖灵护符（短暂无敌）和稀有叠层符文会随战斗掉落。吸血符文为每层每次命中回复 0.2 点生命、单只怪 2% 掉落、最多 8 层；另有战意（伤害 +3%，最多 10 层）、岩甲（受伤 -2.5%，最多 8 层）、疾风（移速 +3%，最多 8 层）与回响（主动技能冷却 -3%，最多 8 层）。符文总掉率约 5.1%，每只怪最多掉落一枚。
- 地形：第一阶段会随机混用礁石与大型海岸礁石，第二阶段会随机混用古树、倒根和大型树桩，第三阶段会随机混用熔岩岩柱、细节熔岩石柱、熔岩巨石、遗迹石柱和大型遗迹石门；它们会阻挡主角和所有敌人，敌人会用局部侧移绕开障碍，不会穿过障碍物。
- 主角：使用 `assets/evolution-guide.webp` 中经去底处理的 3×3 方向精灵；手机竖屏和电脑横向下视觉尺寸都与碰撞体同步收紧。
- 敌人贴图：野人和中世纪步兵分别使用 `assets/savage.webp`、`assets/infantry.webp` 的 3×3 方向精灵；无尽 Boss 使用对应的 WebP 贴图，PNG 仅作为兼容回退。
- Boss：真正的 Boss 出现后，画面中上方显示实时血条；半血进入狂怒阶段；无尽 Boss 还会随机获得迅袭、铁脊、腐化词缀；精英使用金色浮动血条并击败后额外掉落符文；每轮结束后可从三项轮回祝福中选择一项。脉冲升级后会扩大范围、提高伤害，并在释放后短暂免疫迟滞、禁锢、灼烧等 Debuff，同时清除当前异常。
- 音乐：点击难度开始游戏后，浏览器会以约两倍增益合成并循环播放更有战斗节奏的 8 秒无缝音乐；三个生态、三个 Boss 与三段狂怒阶段各有变奏，切换会短暂交叉淡化，结算或返回难度页后停止。
- 积分：不同怪物按强度给分，试炼难度同类怪物分值更高；每个经验球固定提供 1 点经验。游戏 HUD 右上角实时显示积分，结算页可填写名字保存本轮成绩并查看历史榜单。当前榜单安全保存在浏览器本地；跨设备共享需要接入后端排行榜接口，前端不保存任何密钥。
- 反馈：主角受击会有短暂的红色脉冲、碎光和轻微震动。

运行逻辑自检：`node game.test.mjs`
