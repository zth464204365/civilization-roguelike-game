# 文明火种

一个无需安装的横屏蛮荒生存肉鸽原型。直接用浏览器打开 `index.html`，选择难度即可试玩。

- 资源：进入菜单时先完成第一阶段（含 Boss、地形、遗迹、主动技能）的贴图加载；开始第一阶段后后台预载第二阶段，进入第二阶段后预载第三阶段。加载失败仍会保留简易图形兜底并在控制台标明素材路径。
- 手机：横屏游玩；左下方向圆盘移动，右下四键为脉冲、疾驰、飓风和护壁。摇杆与技能键使用独立触点，可双指同时移动与释放技能。主角保持在屏幕中央，生态世界会持续卷动。
- 电脑：WASD 或方向键移动；空格释放「演化脉冲」，Q「疾驰」穿过险境，E 投出「飓风」，R 开启「祖灵护壁」。
- 难度：游猎、迁徙、试炼三档分别影响敌人生命、伤害、速度、刷新频率、受击间隔与补给频率；同一种怪物的基础移速倍率依次为 0.90 / 1.00 / 1.13。
- 关卡：潮痕海岸 → 苔木密林 → 火山荒原；每阶段战斗 40 秒后出现本阶段 Boss：潮涌巨蟹、古木守卫、赤焰巨猿。Boss 战不会消耗下一阶段倒计时。
- 战斗：自动攻击会经历萌芽 → 猎手 → 火种三段成长；升级时还可学习连锁电弧与旋骨飞轮。环绕攻击使用羽扇贴图；三项主动技能分别提供闪避、飓风穿透与减伤解弹。开放地图会持续出现遗迹，击破后可将 Q/E/R 分别升至 10 级，后段数值会渐进膨胀。
- 敌技：双发酸液、蓄力冲刺、震击、护壳、孢子扇射、投矛、毒液禁锢区、贴图火焰与 Boss 二阶段火扇等技能会因生物而异；砂砾虫与野人低血量时会狂暴并提前冲刺，步兵投矛后短暂举盾。
- 拾取：野果（回复）、火种（重置脉冲）、兽骨（穿透）、引力晶核（吸收全图样本）、疾风孢子（加速）、祖灵护符（短暂无敌）和稀有叠层符文会随战斗掉落。吸血符文为每层每次命中回复 0.2 点生命、单只怪 2% 掉落、最多 5 层；另有战意（伤害 +3%，最多 6 层）、岩甲（受伤 -2.5%，最多 5 层）、疾风（移速 +3%，最多 5 层）与回响（主动技能冷却 -3%，最多 5 层）。符文总掉率约 5.1%，每只怪最多掉落一枚。
- 地形：第一阶段使用礁石贴图、第二阶段使用古树贴图、第三阶段使用熔岩岩柱贴图；它们会阻挡主角和地面敌人，飞行生物可越过障碍。
- 主角：使用 `assets/evolution-guide.png` 中经去底处理的 3×3 方向精灵；横屏下视觉尺寸与碰撞体同步收紧，保持更接近元气骑士的屏占比。
- 敌人贴图：野人和中世纪步兵分别使用 `assets/savage.png`、`assets/infantry.png` 的 3×3 方向精灵。
- Boss：赤焰巨猿出现后，画面中上方显示实时血条；半血进入狂怒阶段。
- 音乐：点击难度开始游戏后，浏览器会以约两倍增益合成并循环播放更有战斗节奏的 8 秒无缝音乐；三个生态、三个 Boss 与三段狂怒阶段各有变奏，切换会短暂交叉淡化，结算或返回难度页后停止。
- 积分：不同怪物按强度给分，试炼难度同类怪物分值更高；每个经验球固定提供 1 点经验。游戏 HUD 右上角实时显示积分，结算页可填写名字保存本轮成绩并查看历史榜单。当前榜单安全保存在浏览器本地；跨设备共享需要接入后端排行榜接口，前端不保存任何密钥。
- 反馈：主角受击会有短暂的红色脉冲、碎光和轻微震动。

运行逻辑自检：`node game.test.mjs`
